## Version 0.1.1
**Date:** 2026-03-30
**Summary:** Hotfix for Teacher Analytics.

### Changes & Improvements:
- **Bug Fix**: Resolved a `jinja2.exceptions.TemplateSyntaxError: unexpected '}'` crash on the `/teacher/analytics` dashboard caused by an unclosed `{{ dist_values | tojson }}` expression inside the chart script.
- Backed up to local `version_0.1.1` snapshot.

## Version 0.2
**Date:** 2026-03-30
**Summary:** Added Global Search functionality.

### Changes & Improvements:
- **Search Subjects & Lessons**: Users can now use the search bar on the homepage to instantly find courses by name and description, or individual lessons by title and content.
- **Dynamic Display**: Added responsive "Matching Lessons" and "Search Results" grids dynamically injected onto the homepage.
- **SQLAlchemy Optimizations**: Updated `/` route logic to safely execute case-insensitive `ILIKE` searches via `or_` conditions.
- Snapshotted as `version_0.2` system-wide.

---

## Version 0.2.1
**Date:** 2026-03-30
**Summary:** Hotfix for Lecture Creation Form.

### Changes & Improvements:
- **Bug Fix**: Resolved an issue where the "Publish Content" button would do nothing when creating a new lecture. This occurred because HTML5 validation was preventing form submission on hidden TinyMCE elements.
- **Solution**: Added `novalidate` to the lecture creation `<form>` in `teacher/builder.html` and implemented a visual error block to display Backend (Flask-WTF) validation messages seamlessly.
- Snapshotted as `version_0.2.1`.
