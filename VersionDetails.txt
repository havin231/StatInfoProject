## Version 0.3
**Date:** 2026-04-01
**Summary:** Implemented Comprehensive Kurdish Sorani (ckb/ku) Localization Setup.

### Changes & Improvements:
- **Database Schema**: Added `preferred_lang` column to `User` and `Student` models to persist user language choice.
- **Backend Refactoring**: Adapted routing files (`admin.py`, `analytics.py`, `teacher.py`, etc.), flash messages, WTForms, and controllers to utilize `gettext` (`_`) and `lazy_gettext` components dynamically.
- **Frontend Refactoring**: Refactored `base.html` for RTL (Right-to-Left) rendering and implemented Jinja translation placeholders. 
- **PyBabel Translation Engine**: Generated `babel.cfg`, extracted strings to `messages.pot`, and initialized the Kurdish directory (`ku`) containing `messages.po` templates and `.mo` libraries.
- Snapshotted as `version_0.3`.

## Version 0.3.3
**Date:** 2026-04-01
**Summary:** Fixed Kurdish Translation Toggle Cache Issue.

### Changes & Improvements:
- **Bug Fix**: Resolved critical issue where language toggle was not switching translations to Kurdish despite session being updated correctly.
- **Root Cause**: Flask-Babel was caching the locale upon first access, preventing dynamic language switching during the same request cycle.
- **Solution Implementation**: 
  - Added `has_request_context()` checking in `select_locale()` to prevent RuntimeError when accessing session outside request context.
  - Enhanced debugging with detailed logging in `select_locale()` and `set_lang()` routes to trace language switching flow.
  - Added `flask_babel.refresh()` call in `/set-lang/<lang>` route to force cache refresh after session update.
  - Created `/test-lang` debug endpoint for real-time translation verification.
- **Backend Refactoring**: Improved session handling and locale selection logic with proper fallback mechanisms.
- **Testing**: Comprehensive test suite verified language switching works correctly in both directions with proper RTL support.
- Snapshotted as `version_0.3.3`.
